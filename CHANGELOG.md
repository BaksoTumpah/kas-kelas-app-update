# Riwayat Versi Kas Kelas

Satu bagian per versi, judul `## X.Y.Z`. Isi bagian ini otomatis dipakai sebagai catatan GitHub Release
dan dikirim ke situs ApkSwift saat APK dibangun. Tulis singkat saja.

## 4.1.10
Perbaikan: popup panjang (mis. Tunggakan Lama) kini bisa digulir dengan sentuhan.

## 4.1.9
Fitur guru wali: menu Data > Data Wali (nama, panggilan, NIP, mapel). Wali login di website lewat NISN/NIS dengan NIP + token lihat saja, melihat ringkasan kas, daftar tunggakan (bisa disalin), membuat pengumuman, komentar bertanda khusus. Website: popup kini mengunci gulir halaman di belakangnya.

## 4.1.8
Halaman Tentang kini berguna: cek pembaruan langsung, catatan versi, info kelas, salin info untuk developer. Titik merah menu Aplikasi tidak lagi menggeser panah. Versi terbaru di aplikasi, website, dan bot kini otomatis dari GitHub Release.

## 4.1.7
Keamanan: NISN, NIS, dan tanggal lahir siswa dipisah dari data yang bisa dibaca anggota, login diverifikasi server, token baru lebih kuat. Pantauan kesehatan server untuk bot developer.

## 4.1.6
Fitur baru: tombol undo/redo dengan konfirmasi, laporan PDF (pilih bulan atau semua bulan), kolom kembalian dan warna per nominal di file backup, nama siswa merah kalau punya tagihan bulan lalu, menu hamburger dirapikan jadi dropdown. Perbaikan: popup tidak lagi meneruskan klik dan gulir ke halaman di bawahnya.

## 4.1.5
Fitur baru: menu Cek Pembaruan Aplikasi (update otomatis dari GitHub, izin pasang dicek dulu), pilihan dropdown bergaya aplikasi, bulan merah kalau ada tunggakan dan hijau kalau lunas, kolom NIS siswa. Perbaikan: scroll lebih ringan.

## 4.1.4
Tampilan baru sama dengan website, semua emoji dihapus, keamanan diperkuat, perbaikan bot Telegram dan sinkron Tugas.
