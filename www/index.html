Nilai & Jadwal Checklist

Berlaku untuk bulan yang sedang dipilih di beranda.

Uang yang dibayar satu siswa untuk satu tanggal (satu kotak centang). Contoh: ketik 2000 artinya Rp2.000 per siswa tiap tanggal kas. Berlaku untuk seluruh tanggal bulan ini; kalau ada tanggal dengan nominal berbeda, pakai "Tarif berbeda per tanggal" di bawah. Ketik angka saja, tanpa titik.

Nominal per siswa per tanggal. Contoh: tanggal 1–15 Rp5.000 tiap hari, tanggal 16–30 Rp2.000 hanya Selasa & Kamis. Tiap rentang membuat tanggal iuran dengan nominalnya sendiri. Kosongkan hari = tiap hari.

Aplikasi terkunci

Kunci Aplikasi

Saat aplikasi dibuka lagi, kamu harus membuktikan bahwa itu kamu: sidik jari bawaan HP, NFC tag, atau token. Pengaturan ini hanya berlaku di HP ini.

Isi NFC tag berupa teks yang bisa dibaca aplikasi NFC apa pun, jadi simpan tag seperti kunci. Kalau token diganti, tulis ulang tagnya. Tanpa sidik jari/NFC, buka kunci tetap bisa dengan mengetik token.

Pengingat Tagih Kas

Hari tagih mengikuti menu Nilai & Jadwal Checklist (hari kas ditarik) dan tanggal yang ditandai libur. Pengaturan ini hanya berlaku di HP ini.

Lapor ke Developer

Ada masalah internal (error, data tidak sesuai, fitur tidak jalan)? Tulis singkat dan jelas. Laporan masuk ke halaman kontrol developer dan Telegram developer.

Kategori Pengeluaran

Template bawaan sudah disediakan. Tambah kategori sendiri atau hapus yang tidak dipakai (pengeluaran lama tetap menyimpan nama kategorinya).

Impor Data Siswa

Pilih file .xlsx (atau .csv) dari Excel / Google Sheets. Baris pertama harus berisi judul kolom. Kolom yang dikenali:

No · NISN · Nama Lengkap (wajib) · Nama Panggilan · Tanggal Lahir (mis. 11-06-2008 atau 11 Juni 2008) · Kelas

Daftar Tunggakan

Urut sesuai absen, hanya siswa yang menunggak, memakai nama pendek seperti di dashboard. "k" = ribuan rupiah.

Token Aktif

Token yang sedang berlaku untuk kelas ini. Hanya admin yang bisa melihat ini. Jangan bagikan Token Editor. Ketuk 👁 untuk menampilkan.

Kembalian Belum Diberikan

Backup Spreadsheet

Unduh file .xlsx (1 sheet per bulan + sheet "Rekap") ke penyimpanan HP, atau pakai menu "Sinkron Akun Google Drive" untuk simpan langsung ke Drive.

Dijalankan server pada hari dan jam yang dipilih (bawaan 15.00 WITA). File masuk ke Drive pemilik bot: folder "Backup Kas Kelas (nama kelas)" / "Backup Otomatis". Hanya 1 file tersimpan: file backup otomatis sebelumnya dihapus setiap backup baru berhasil.

Laporan kas bulanan (PDF)

Satu laporan rapi: ringkasan, pemasukan, pengeluaran, dan daftar tunggakan. Siap dicetak atau dikirim ke wali kelas.

Restore dari file backup

Pulihkan seluruh data dari file .xlsx hasil backup (manual maupun otomatis, dari Drive/Telegram/unduhan). Hanya file yang dibuat oleh versi aplikasi/server ini yang bisa dipakai. Khusus Admin.
